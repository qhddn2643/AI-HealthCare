# 분석 코드 정적 검토

| 프로젝트 | 확인한 위험 | 이번 처리 |
|---|---|---|
| 흡연 | 전체 자료로 결측 대체 후 모델 분리; 나이 20 미만을 70대 초과로 분류하는 else; 중성지방 400 초과의 반환 누락 | 계산은 유지하고 한계를 문서화. 모델 점수 미기재 |
| 난임 | 전처리 후보를 같은 개발 집단에서 먼저 선택; 환자별 반복 시술/기록 시점 확인 부족 | 누수 해소를 보증하지 않음. 이력 6개 제외와 학습 fold 기준 변환을 확인 |
| SmartDUR | 대리 라벨·선택 편향·양성 9건·기존에 조회한 hold-out·라벨 관찰기간 경계·처방 종료시각의 사후 수정 가능성 | 원 검증 설계 유지, 주 분석/민감도 구분, 시점 가용성 추가 확인으로 명시 |

개인 절대경로·Colab 마운트·Linux 설치 명령을 공개 복사본에서 제거했습니다. 노트북 출력·실행 번호·첨부 이미지는 비웠고 개인 분석 집계 차트 하나만 별도로 추출했습니다. 원본 셀 순서와 계산식·모델 파라미터는 유지했습니다. 코드 셀 출처 번호는 notebook metadata의 source_cell_index에 있습니다. 모델 학습은 명시적 활성화로 제한했습니다.

장시간 학습·GPU 학습·전체 Notebook 재실행은 하지 않습니다. 전처리 함수 변경이나 성능 개선 실험은 이번 포트폴리오 정리 범위에 포함하지 않았습니다.

코드 공개 요청에 따라 세 프로젝트의 Notebook 3개와 SmartDUR Python 모듈 3개를 모두 포함했습니다. SmartDUR의 검토 결정 파일과 실행 환경 lock도 `outputs/`에 저장하도록 입출력 위치만 조정했습니다. 입력 자료와 개별 결과를 저장소로 복사하지 않았습니다. 새 테스트는 원시 데이터 없이 문법·학습 중단·검토 근거 누락 거부·공개 범위를 확인합니다.
