# 공개 대상 및 제외 검토

범위는 현재 oz-healthcare 워크스페이스입니다. 홈·다른 로컬 저장소는 탐색하지 않았습니다. AI-HealthCare는 기존 원격 main의 첫 커밋에서 Clone한 별도 복사본입니다. 원본 파일을 삭제하거나 수정하지 않았습니다.

| 제외 파일/종류 | 이유 |
|---|---|
| 모든 원시 CSV/XLSX·의료 이미지·개별 기록 | 원 출처/재배포 권한 불명, 의료 특성·재식별 위험 |
| SmartDUR *PRIVATE*, 개별 예측·위음성·토큰·감사 기록, 가상 EMR/시뮬레이터 | 원본 안내에 내부 사용 제한, 의료 특성/연결 토큰 포함 |
| 저장 모델, weights, checkpoints, npy/npz | 데이터 누출·용량 및 배포 권한 미확인 |
| 강의 PDF/PPTX/DOCX·다른 조 자료·원본 팀 발표·ZIP·중복 버전 | 저작권·공유 권한 미확인 또는 중복 |
| .env·가상환경·캐시·.analysis_deps | 인증정보·개인 환경·불필요한 용량 |
| 기존 Velog 초안·이력서 | 이번 포트폴리오 범위 밖의 개인 문서 |

포함: 개인 명의 흡연 코드 노트북 1개, 새 README·설정·검사 도구·학습 주제 메모, 개인 평균 비교 차트, 팀 실행 기록의 집계 지표만 포함합니다. 난임·SmartDUR 팀 소스 5개(노트북 2개·모듈 3개)는 공개 권한 미확인으로 제외하고 로컬 검토 폴더에 보관했습니다. 팀 코드의 개별 기여를 추정하지 않았습니다. 집계 결과를 포함한 공개 범위도 Push 최종 승인에 포함합니다.

기존 원격 이력은 README만 있는 1개 커밋입니다. 검사 도구는 현재 tracked 파일과 모든 도달 가능한 과거 blob을 검사합니다. 정규식 검사 통과는 수동 검토를 대체하거나 비밀정보 부재를 보증하지 않습니다. 이력을 재작성하지 않습니다.
