# 코드 공개와 데이터 제외 범위

사용자의 코드 공개 요청에 따라 난임·SmartDUR 코드도 포함했습니다. 범위는 현재 워크스페이스의 선정된 세 프로젝트입니다. 원본은 보존하고 공개용 복사본을 사용합니다.

| 포함 | 내용 |
|---|---|
| Python 모듈 3개 | SmartDUR 모델링·라벨 감사·시각화 |
| Notebook 3개 | 흡연 EDA·난임 모델 비교·SmartDUR 실행 코드. 모든 셀 출력·실행 번호·첨부 제거 |
| 설명과 개발 설정 | 프로젝트별 README, requirements, VS Code 설정, 검사 도구, 학습 주제 메모 |
| 기존 집계 결과 | 과거 기록의 집계 지표 JSON·대표 차트. 원시 의료 기록 아님 |

| 제외 | 이유 |
|---|---|
| 입력 CSV/XLSX·의료 이미지·모든 원시 기록·ZIP | 사용자가 데이터 제외 요청 |
| 개별 예측·연결 토큰·감사 기록·위음성 목록·가상 EMR | 개별 의료 특성과 원자료 연결 가능성 |
| 모델·가중치·체크포인트·npy/npz | 데이터 제외 범위에 포함, 불필요한 용량 |
| 강의 PDF/PPTX/DOCX·다른 조 발표·중복 원본 | 선정 코드 외의 교안·원본 산출물 |
| .env·가상환경·캐시·개인 경로 | 인증정보·로컬 환경 제외 |

`data/`는 README만 허용하며 `outputs/`·`results/`는 게시하지 않습니다. 비표준 확장자로 데이터를 추가해도 검사 도구가 해당 디렉터리의 파일을 거부합니다. 원본 팀 노트북의 코드임을 표시하며 개인 단독 기여로 바꾸지 않았습니다. 코드에 포함된 컬럼명·분석 임계값은 계산 로직이고 실제 환자별 레코드는 포함하지 않습니다.

Git index의 내용과 과거 이력 blob을 검사합니다. 기존 `main` 이력을 재작성하지 않으며, 검사 통과가 모든 위험의 부재를 보장하는 것은 아닙니다.
