# 데이터 준비

이 저장소는 분석 코드를 제공하며 입력 데이터는 포함하지 않습니다. 승인된 팀 패키지를 `data/package/`에 풀고 원 ZIP을 `data/package.zip`으로 둡니다. 필요한 구조는 다음과 같습니다.

```text
data/
├── package.zip
└── package/
    ├── 01_최종결과/   # MAIN·MASTER·모델입력 목록 CSV
    └── 05_원본데이터/ # 15_·16_ 접두사의 원본 경고/중재 CSV가 들어 있는 ZIP
```

다른 패키지 하위 폴더도 원래 구조를 유지합니다. `SMARTDUR_PACKAGE_DIR`과 `SMARTDUR_ARCHIVE`로 두 위치를 지정할 수 있습니다. 소스가 패키지 내 파일과 원 ZIP의 SHA-256 일치를 검사하므로 승인된 입력 세트를 함께 준비해야 합니다.

실행 결과·개별 감사 파일·모델은 프로젝트의 `outputs/`에 생성하며 이 폴더도 Git에서 제외합니다.

교육과정 또는 팀 담당자에게 승인된 전달 경로를 확인해 직접 확보하세요. 확인되지 않은 원 출처 URL이나 자동 다운로드 경로를 만들지 않았습니다. 원 데이터의 이용·공유 조건은 별도로 따라야 합니다.

`data/`는 이 README 외의 모든 파일을 Git에서 제외합니다. 행별 노트북 출력·개별 예측·환자 기록·학습 모델은 업로드하지 않습니다. 원본에서 검토한 성능표·통계 요약·집계 그래프는 Notebook에 보존합니다. 원본 파일이나 예시용 환자 기록은 생성하지 않았습니다.
