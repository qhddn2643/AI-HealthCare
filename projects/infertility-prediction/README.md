# 난임 시술 정보 기반 임신 성공 예측

## 프로젝트 개요

5조 팀 작업에서 저장된 XGBoost·CatBoost 비교 실험을 정리했습니다. 최신이라는 파일명만으로 여러 실험을 섞지 않고, 별도 실행 JSON과 연결되는 ‘신규 XGBoost + CatBoost 앙상블 실험’ 노트북을 선택했습니다. 개인별 기여 범위는 확인되지 않아 팀 코드로 표시합니다.

## 문제 정의와 목표

시술 관련 입력에서 임신 성공 여부를 예측하는 이진 분류입니다. 모델별 ROC-AUC와 평균 앙상블을 같은 검증 설계에서 비교합니다.

## 데이터 출처 및 특징

교육과정 제공 train/test/제출 양식입니다. Train은 256,351행·69열로 확인했습니다. 원 출처·이용 약관·재배포 허가는 자료만으로 확인하지 못해 데이터와 행별 예측을 제외했습니다. [데이터 준비](data/README.md).

## 전처리 및 EDA

학습 fold에서 범주 사전과 IQR 기준을 만들고 결측·0 플래그 및 시술 유형별 결측 처리를 비교합니다. 기록 시점이 모호한 임신·출산 이력 6개는 제외한 실험입니다. 이를 실제 누수로 확정한 것은 아닙니다.

## 모델링 또는 분석 방법

XGBoost 3개 시드와 CatBoost를 비교합니다. CatBoost 반복 수는 외부 학습 fold 안의 내부 분할에서 선택합니다. 두 예측 확률의 50:50 평균을 비교 후보로 둡니다.

## 평가 방법 및 결과

2026-10-16 실행 JSON에 저장된 값입니다. 신규 실행값이나 공식 대회 성적이 아닙니다.

| 모델 | CV 평균 ROC-AUC | CV 표준편차 | 보고용 hold-out ROC-AUC |
|---|---:|---:|---:|
| XGBoost | 0.738193 | 0.003318 | 0.734669 |
| CatBoost | 0.737818 | 0.003373 | 0.734334 |
| 50:50 평균 | 0.738298 | 0.003329 | 0.734700 |

원래 숫자와 버전은 [경로를 제거한 실행 기록](assets/recorded-metrics.json)에 있습니다. 차이가 작아 일반적인 성능 향상으로 단정하지 않습니다.

## 한계점 및 개선 방향

전처리 방식은 같은 개발 집단에서 먼저 선택하므로 이후 OOF 평가에 선택 편향이 남을 수 있습니다. 모든 선택을 포함한 중첩 검증이 필요합니다. 환자 ID 기반 분리와 예측 시점별 입력 가용성은 추가 확인 대상입니다. 원본 파라미터는 반올림된 튜닝 출력값이므로 원 실행의 완전 동일 재현은 보장하지 않습니다.

## 실행 방법

[분석 Notebook](notebooks/analysis.ipynb)에 팀 모델 비교 코드를 포함했습니다. 개인 절대경로·Colab 마운트·폰트 파일 경로를 제거했습니다. 원본에 저장된 결측/이상치 요약·전처리 비교표·CV/hold-out 성능표·ROC·변수 중요도 그래프를 복원했고 원시 행·예측 배열·경고 로그는 제외했습니다. 저장된 실행 번호를 유지한 과거 결과이며 이번 작업의 재학습 결과가 아닙니다. 원본 셀 순서는 유지하며 출처 셀 번호는 metadata에 기록했습니다.

```powershell
# 저장소 루트에서
python -m pip install -r projects/infertility-prediction/requirements.txt
```

[데이터 준비](data/README.md)에 따라 `train.csv`, `test.csv`, `sample_submission.csv`를 로컬 `data/`에 둡니다. 다른 위치라면 커널을 실행하기 전 `HEALTHCARE_DATA_DIR` 환경변수를 설정합니다. `notebooks/analysis.ipynb`를 해당 프로젝트 또는 notebooks 폴더를 작업 경로로 열고 위에서 아래로 실행합니다.

`ALLOW_TRAINING=False`가 기본값이며 교차 검증 전에 중단합니다. 사용자가 직접 `True`로 변경하면 원본 5-fold·3시드 비교가 진행되어 시간이 걸릴 수 있습니다. 새 제출 파일과 실행 JSON은 `outputs/` 아래에 저장되어 Git에서 제외됩니다. 데이터·행별 예측·모델은 업로드하지 않습니다. 전체 학습을 이번 공개 작업에서 다시 실행하지 않았습니다.
