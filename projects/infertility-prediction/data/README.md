# 데이터 준비

승인된 train.csv, test.csv, sample_submission.csv를 이 폴더에 둡니다.

원 출처·라이선스·공개 재배포 허가를 확인하지 못해 데이터는 배포하지 않습니다. 교육과정 또는 팀 데이터 담당자에게 승인된 다운로드/전달 경로를 확인해 직접 확보하세요. 출처 URL을 추정하거나 자동 다운로드하지 않습니다. 데이터 디렉터리는 이 README 외에 Git에서 제외합니다.

흡연·난임 노트북은 HEALTHCARE_DATA_DIR로 다른 로컬 입력 경로를 지정할 수 있습니다. 예제용 환자 기록도 생성하지 않았습니다.
