# 데이터 준비

이 저장소는 분석 코드를 제공하며 입력 데이터는 포함하지 않습니다. 승인된 `smoking_health_data.csv`를 이 폴더에 둡니다.

흡연·난임 노트북은 `HEALTHCARE_DATA_DIR`로 다른 로컬 입력 위치를 지정할 수 있습니다.

교육과정 또는 팀 담당자에게 승인된 전달 경로를 확인해 직접 확보하세요. 확인되지 않은 원 출처 URL이나 자동 다운로드 경로를 만들지 않았습니다. 원 데이터의 이용·공유 조건은 별도로 따라야 합니다.

`data/`는 이 README 외의 모든 파일을 Git에서 제외합니다. 노트북 출력·행별 예측·환자 기록·학습 모델도 업로드하지 않습니다. 원본 파일이나 예시용 환자 기록은 생성하지 않았습니다.
